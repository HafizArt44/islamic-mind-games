# Islamic Mind Games — Android project

یہ موبائل گیم کا ابتدائی ترمیم شدہ ورژن ہے۔ برانڈ نام **Islamic Mind Games** رکھا گیا ہے، ڈیزائن کو نرم سبز، سفید اور سنہری رنگوں کی طرف کیا گیا ہے، اور EN / اردو / العربية زبان بدلنے کا کنٹرول شامل کیا گیا ہے۔ زبان کا انتخاب فون پر محفوظ رہتا ہے۔

## اہم بات

یہ ورژن ابتدائی کام ہے: اس میں ہوم اسکرین اور ہوم اسکرین، موڈز، سطحوں، بیجز اور عام گیم پیغامات کے لیے انگریزی، عربی اور ہندی ترجموں میں اضافہ کیا گیا ہے۔ سوالات کے تمام متحرک جملوں اور ہر مواد کے مکمل انسانی ترجمے ابھی بھی مرحلہ وار جانچنے باقی ہیں؛ اس لیے اسے حتمی اشاعتی ورژن نہ سمجھیں۔ APK بنانے سے پہلے فون پر ہر موڈ ٹیسٹ کریں۔

## GitHub سے APK بناتے وقت

ZIP کھول کر اس کے اندر موجود تمام فائلیں (بشمول `.github` فولڈر) GitHub repository کی جڑ میں اپلوڈ کریں؛ `islamic-mind-games` نام کا کوئی اضافی فولڈر repository کے اندر نہ بنائیں۔ پھر Actions میں **Build Android** ورک فلو چلائیں۔

- App label: Islamic Mind Games
- Application ID ابھی `com.islamicpuzzle.app` ہے؛ Play Store پر پہلی اشاعت سے پہلے اسے اپنے منفرد ID میں بدلیں۔
- فونٹ فائلیں ابھی شامل نہیں؛ اس لیے اردو/عربی کی ظاہری شکل فون کے دستیاب فونٹس پر منحصر ہو سکتی ہے۔
- اس ورژن کو ابھی Android SDK کے ساتھ compile یا حقیقی فون پر مکمل ٹیسٹ نہیں کیا گیا۔
